# UX brainstorming

Make the decision visible. Use Superdesign for visual review, then carry accepted decisions into the implementation.

Read the brief, accepted design and relevant source. Establish the exact surface: a journey, whole page, section or component. Reuse the current project/draft and any valid saved design context. Follow [the Superdesign integration](references/superdesign.md) before calling its tools.

Frame the unresolved visual question and recommend a direction. Show a small set of meaningful alternatives when a choice is needed; explain how each serves the audience/action and what changes in the experience. Give the user the real canvas/preview link from the tool result. Code pasted into chat is not the visual review artifact.

When the user wants detail, work component by component. Freeze accepted surroundings, iterate the selected component, review its states and responsive behavior, then assemble it into the page. A local correction should update the selected direction; create a branch when the user wants alternatives to compare. Do not regenerate the whole landing page for a selected-section change.

Record the accepted direction using [the design handoff](references/design-handoff.md): design references, matching source components, important states, acceptance and open questions. This is a maintained correspondence, not deterministic canvas-to-code synchronization.

If provider access is unavailable, state that fact and prepare the brief/context that can be completed locally. Do not invent a draft or link. Ask for the needed connection only when it blocks the requested visual; offer a local visual alternative if useful, and label it accurately.

Example: after a graph section is accepted, explore the next funnel section independently, choose its representation, and check its assembled transition with the graph. Preserve the accepted graph unless the user changes that scope.

Ready-to-build means the affected experience and visual decisions are settled. It does not authorize Cloudflare production publication.
